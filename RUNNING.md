# Running the game

This is a Java 21 desktop game built with libGDX and Gradle.

From the project root, run:

```powershell
gradle :lwjgl3:run
```

Gradle downloads the libGDX desktop dependencies the first time it builds. Use **WASD** or the arrow keys to walk around Fernwood. Press **Enter** or **Space** to start a battle. Choose a battle action with the mouse; **Escape** runs from battle or closes the game from the overworld.
